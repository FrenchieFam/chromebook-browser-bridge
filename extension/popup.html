A work tab that reconnects itself

Keeps one designated pinned tab connected. After Chrome restarts, or if that tab closes, it restores a work tab at this start page. If Linux is off, it retries once a minute when Linux is available.

Canceling Chrome’s debugging banner also pauses recovery until you start it again. Your other tabs are not followed automatically. Chrome’s banner stays visible while connected.

Connected pages—including signed-in pages—can be read and operated through the local Linux bridge. Enter passwords yourself. Internal chrome:// pages and desktop dialogs remain unsupported.
